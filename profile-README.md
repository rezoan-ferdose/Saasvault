## Notes on writing it

- **One link per line.** A profile with twelve links in a bio reads like a link farm, and GitHub profiles are among the surfaces spammers burn out first.
- **Put the website in the profile field too.** Settings → Public profile → Website. That field is separate from the README and is the one that shows next to every comment you make.
- **`<username>/<username>.md` is the profile repo.** Create a repo named exactly your username, put this file in it as `README.md`, and tick "Commit changes to main branch" — GitHub renders it on your profile page. Make it public.
- **Add a `funding.yml` only if the links are real.** `.github/FUNDING.yml` with a live sponsor page is a legitimate signal; an empty one is noise.
- **Nothing here is about PageRank.** The point of a followed link is that Googlebot visits this page constantly, so the URL it points at gets seen sooner. It does not transfer authority you can count on.
- **A repo with real content outperforms a decorated profile.** Stars, forks and issues on something usable are the strongest thing GitHub gives you — and a repo like this one is exactly that kind of content.
- Do not paste a promo code, a countdown banner, or "🚀 SaaS founder | AI enthusiast | 20x". Write the sentence a person would say to another person.
